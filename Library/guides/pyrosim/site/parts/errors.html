Error finder

The failures that say nothing are the ones that cost you a day

FDS returns a success status even when it fails, and several of the worst beginner mistakes produce no error at all. The table below is the working list. The rows marked silent finish with STOP: FDS completed successfully and a wrong answer; those are the ones to learn by heart.

Type any part of a message, a symptom or a keyword to filter. Every message shown here was either produced on a real run or read from the FDS source at the 6.10.1 release tag.

The run finishes, but a pressure zone appearsPressure Zone Information — 1 Volume: 2.0732E+01 m3silent The room has no path to the outside. FDS treats the domain edge as a solid wall unless an OPEN vent says otherwise, and it treats a sealed space as genuinely sealed, so the pressure climbs instead of the smoke leaving. Right-click the mesh and choose Open Mesh Boundaries, and check the door actually cuts through. A volume close to the room's own volume in that line means the room is the sealed zone.
The door is drawn but the room is still sealedsilent The hole is shallower than the wall, so it does not punch through. In FDS a HOLE must overlap both faces of the OBST; in PyroSim the Wall Hole tool has its own Wall Thickness, which defaults to 0.2 m and must be at least as thick as the wall. Set the tool's Wall Thickness to match the wall, or in the text file extend the hole a centimetre past each face, as the reference case does with XB=3.59,3.71 through a wall at 3.6 to 3.7.
The fire is far too smallsilent HRRPUA is a heat release rate per square metre. Typing the total kilowatts into it makes the fire smaller by the burner's area in square metres. Divide: the ISO burner is 0.17 × 0.17 m, so 100 kW is 3460 kW/m². Check the HRR column of CHID_hrr.csv against what you intended before trusting anything else in the run.
The burner is visible but HRR stays at zerosilent The vent is smaller than a cell, or its edges round to the same grid line, so FDS drops it. It does not appear in the vent list in the .smv file either. Draw the burner on cell boundaries and at least one cell across. Use Snap to Model Grids and check the burner in FDS Block Preview.
A sensor column is missing from the CSVWARNING: DEVC S2_T is not within any mesh.silent The device sits outside every mesh. FDS skips it and carries on, and the warning goes to the console only — there is no line in the .out file. Move it inside the mesh. Read the run log rather than only the CSV; in PyroSim the log is the text in the FDS Simulation dialog, and Save Log keeps it.
CO and smoke stay at zero all runsilent The reaction has no yields. FDS defaults CO_YIELD and SOOT_YIELD to zero, and the library's FDS6 fuel entries, propane included, set only the fuel. Visibility then sits at its 30 m cap and part of the exposure dose never accumulates. Open Model › Edit Reactions, go to the Byproducts tab and set both. The reference case uses 0.024 soot and 0.005 CO for propane, the values the FDS Validation Guide adopts from Tewarson's measurements.
A wall or ceiling stays exactly at room temperaturesilent Its surface is still INERT, the default, which holds the surface at the ambient temperature. Give it a layered surface with real materials. Do not reach for ADIABATIC instead: the FDS guide says it is for testing only.
The run stops part wayERROR(374): Numerical Instability - FDS stopped The time step collapsed below one ten-thousandth of its initial value. Documented causes include a sudden large change in heat release, cells with an aspect ratio worse than 2:1, a resolution jump at a mesh interface, high-speed flow through a small opening, and a fire too large for the room's ventilation. Read the last time-step block in CHID.out for the mesh where the CFL number or divergence explodes, then open the final Plot3D file FDS writes in Smokeview and look for the spurious velocities. Ramp the fire instead of stepping it, and keep the domain open beyond the door.
FDS stops while reading the fileERROR(101): Problem with SURF number 2, line number 49 A misspelt or invalid keyword, a missing closing slash, a wrong quote, or a non-ASCII character. FDS names the record type and the line. Go to that line. Note that an unused RAMP with a typo is never read and never complains, so the fault can be in a line you thought was inactive.
ERROR(314): SURF BURNER Must have a REAC line when using HRRPUA or MLRPUA. A burner surface with no reaction defined. Model › Edit Reactions › Add From Library, then set the yields.
ERROR(819): VENT null is OPEN, MIRROR OR PERIODIC and must be on an exterior boundary. An OPEN vent was drawn inside the domain, often on an interior wall where a door was meant. OPEN belongs only on the outside faces of a mesh. Model a door as a hole through the wall.
ERROR(820): VENT 1 has no solid backing or an orientation index (IOR) is needed. The vent is floating in air. A vent must sit on a solid face or a mesh boundary. Put it on the face of an obstruction, or give it an orientation. The 6.11 wording differs: VENT <id> is not attached to any solid surface.
ERROR(431): MESH 2 is out of alignment with MESH 1 Abutting meshes whose cells do not match in cross-section or in an integer ratio. Make the shared face line up. To check without running, set the end time to zero — the alignment error still prints, and the run ends with STOP: Set-up only.
ERROR(112): The number of MPI processes, 2, exceeds the number of meshes, 1 A parallel run asks for more processes than there are meshes. One mesh takes one process. Split the model into more meshes, or run fewer processes. Keep the fire inside one mesh.
ERROR(108): No periods allowed in CHID The job name contains a full stop. Spaces are out too, and the same rule applies to the folder name. Use underscores: room_v1, not room.v1.
ERROR(109): Remove the file, case.stop, from the current directory A previous run was stopped and left its .stop file behind. Delete it, or resume the run with Analysis › Resume FDS, which restarts from the checkpoint.
The run ends immediately with nothing in it A new PyroSim model has a simulation end time of 0.001 s, which must be changed before anything happens. FDS's own default is 1 s. Analysis › Simulation Parameters › Time, set the end time.
FDS runs far slower than expected on Windows Windows Defender scanning the solver. The installer adds exclusions for the bundled FDS, but not for an FDS you point at yourself. Add file and process exclusions for fds.exe and fds_openmp.exe in Windows Security.
The licensing dialog opens at start-up PyroSim cannot find a licence. Help › License. A node-locked licence takes a 22-character activation key, or a licence file generated from the host ID shown in the dialog. A floating licence takes the server name and port 52100.
Parallel runs ask for a password, repeatedly MPI on Windows needs a password-protected account. Set an account password, then in the install's fds\mpi folder run mpiexec -remove, mpiexec -register and mpiexec -validate.
A batch reports success for runs that failed FDS returns exit status 0 after set-up errors and after a numerical instability. The status tells you nothing. Search each log for the exact line STOP: FDS completed successfully, and flag any ERROR(, any device warning and any unexpected pressure zone.
Every variant overwrites the last one's results Output files are named from the CHID, so two runs with the same CHID share files. One CHID per variant, and one folder per variant. In PyroSim use File › Export › Export Scenarios rather than running scenarios one at a time.
The disk fills during a batch Slice, boundary and 3D smoke files are written a thousand times per run by default, whatever the run length. Set the output intervals explicitly on the Output tab, keep only the slices you need, and turn 3D smoke off for data runs.
