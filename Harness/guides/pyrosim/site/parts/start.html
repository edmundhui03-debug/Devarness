PyroSim does not calculate the fire, and knowing that changes how you learn it

PyroSim is an editor. It draws the room, holds the burner and the sensors, and writes them all into a plain text file with a .fds extension. That file goes to FDS — the Fire Dynamics Simulator, written by NIST and free — which does every calculation. When people say "I ran PyroSim", what ran was FDS.

This matters for three reasons. The words you use in a paper are "an FDS simulation prepared in PyroSim", not "a PyroSim simulation". The thing to check when a result looks wrong is the text file, not the drawing. And on Day 7, when one room has to become hundreds of rooms, the text file is what a script can write and PyroSim cannot.

How a day works

Each day has the same three parts. Learn is the idea, in plain words, with the detail folded away until you want it. Build is a numbered list of exactly what to click and type. Check is how to tell whether it worked, against a number rather than a feeling. Five questions close the day; answer them from memory before you open the answers.

The tick next to each day in the sidebar is yours to set, and your browser remembers it. It is stored only on this device.

There is an Ask Peter button in the bottom corner. It sends your question together with the section you are reading, and answers from this page rather than from general knowledge — so it is useful for "what does this step actually mean", and honest about saying when the guide does not cover something. It uses your own Claude account and asks your permission the first time. If it is not available in the view you are in, the button explains that instead.

The reference run

Every number quoted in this guide came out of a real simulation. The case file is iso9705_room.fds, included in full on Day 3, and it was run on a MacBook Air with the same FDS 6.10.1 that your PyroSim carries. Your run will not match it digit for digit — a different machine, a different mesh and a different FDS build all move the numbers — but it should land in the same neighbourhood. Where it does not, Day 6 is about finding out why.

Watch out

The reference run uses 20 cm cells, which is coarse. It finishes in about two and a half hours instead of a day and a half, and it reads cooler than a real ISO 9705 room does. That is a deliberate trade, and Day 6 measures the size of it. Do not quote these numbers in a report as if they were the truth about a room fire.
