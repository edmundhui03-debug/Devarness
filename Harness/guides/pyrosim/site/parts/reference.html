Reference run

Every number in this guide came out of this run

This is the room the whole guide builds: the ISO 9705 test room, 3.6 × 2.4 × 2.4 m, with a 0.8 × 2.0 m door in one end wall and a propane burner in the far corner. The burner holds 100 kW for ten minutes, steps to 300 kW, and holds that for ten more. It is the standard's own ignition programme.

Four things to notice before you build it yourself

  • The heat release rate is an input, not a result. It tracks the programme because you prescribed it. If your HRR column does not, something is wrong with the burner, not with the fire.
  • The smoke layer forms fast and then barely moves. It is down to about 0.9 m within a minute and stays near there for the rest of the run, because the door lets out as much as the fire makes.
  • Visibility fails long before heat does. At the room centre it is under 5 m in the first minute, while the floor is still taking well under 1 kW/m² and the exposure dose is negligible. In a real building the smoke is what stops people leaving.
  • This run reads cool. Dillon measured about 305 °C at 2.35 m for a 100 kW corner burner in a real ISO room, and about 615 °C at 300 kW. This one gives 147 °C and 342 °C. Day 6 is about that gap.

The case files

Four files come with this guide. iso9705_room.fds is the reference case on 10 cm cells; iso9705_room_20cm.fds is the same room on 20 cm cells, which is what produced the table above; day6_broken.fds is the Day 6 exercise; iso9705_template.fds is what Day 7's script fills in. Copy any of them from the listings in this guide, save it with a .fds extension, and open it in PyroSim with File › Import FDS/CAD File.
