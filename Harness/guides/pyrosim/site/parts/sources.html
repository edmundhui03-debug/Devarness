Sources and review

What was checked, what was run, and what is still unverified

The guide cites Thunderhead documentation, NIST FDS guidance and published fire studies. Historical reference values are illustrative; raw run evidence is not distributed with this source checkout. Reproduce measurements from the public cases before relying on them.

What this guide could not establish

  • Screenshots are placeholders, not captures of a current installation. Confirm menu paths and settings in your own licensed PyroSim installation.
  • The guide targets PyroSim 2026.1. If your copy is 2026.2, the solver is identical but a few menu labels differ; where that is known, the text says so.
  • A handful of interface details could not be confirmed without the software on screen: which ramp-up options the burner dialog actually lists, whether auto-save before running is ticked on a fresh install, and the exact install path on your machine.
  • ISO 9705-1:2016 Annex B, which fixes where the standard's own instruments go, is not public. The sensor positions in the reference case are this guide's choices, made to match the educational measurements.
  • The reference run is coarse and reads cooler than measurements of a real ISO room. It is a check on your method, not a statement about fire.
